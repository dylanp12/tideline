# TLR/1 conformance

Three artefacts define the protocol in machine-checkable form.

**`corpus/events.json`** — per-event vectors. For each, `canon_sha256` is the
SHA-256 of the 181-byte canonical form and `hash` is `SHA-256(canon || prev_hash)`.
An implementation conforms when it reproduces both for every vector, including
the awkward cases: absent versus empty fields, Unicode in every field, metadata
whose key order and spacing must survive untouched, a redacted field carrying its
retained digest, and a 100 KB content field.

`event_json` holds the exact source text to parse. Reformatting it changes the
metadata bytes and therefore the hash, which is precisely what two of the vectors
are there to catch.

**`corpus/chains.json`** — whole-chain cases with their expected verdicts:
valid, valid after redaction, edited content, a deleted event, and empty.

**`independent_check.py`** — a second canon implementation sharing no code with
the Rust crate. The corpus is generated by `tideline-proto`, so replaying it in
Rust alone only proves the crate agrees with itself. This script re-derives every
hash from the spec, catching a canon change that is wrong the same way in both
the generator and the verifier.

## Running it

| Surface | Command |
| --- | --- |
| Rust | `cargo test -p tideline-proto --test corpus` |
| Independent | `python3 conformance/independent_check.py` |
| TypeScript | `pnpm --filter @tideline/sdk test` |
| Python | `pytest sdk/python` |
| Go | `go test ./sdk/go/...` |

The TypeScript, Python, and Go runners arrive in Plan 3. All of them read these
same files; none ships its own copy.

## The failure you will hit first

If an implementation reproduces most vectors but fails
`metadata-key-order-is-preserved` or `metadata-spacing-is-preserved`, it is
almost certainly parsing JSON into a generic value and then converting to a
typed structure. That re-serialises the metadata with its keys reordered, which
changes the digest and therefore the hash.

Read the metadata from the original bytes: `serde_json::value::RawValue` in Rust,
`json.RawMessage` in Go, and a byte-span read from the response text in
TypeScript and Python, where the standard parsers keep nothing. See
`independent_check.py` for a worked span reader.

## Changing the corpus

Regenerating it changes the protocol and invalidates every record already
written. Treat a diff here as a breaking change: bump the protocol version,
do not edit a vector in place.
